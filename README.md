# ABD Rotası

Türkiye'den ABD'ye geçiş için hazırlık rehberi (Türkçe / English). Tek dosyalık statik site.

- Vize hazırlık skorları (H-1B, O-1, L-1, E-2, F-1, yeşil kart): bilgiler yalnızca tarayıcıda kalır.
- İş bulma, çalışma izni ve kariyer adımları.
- Randevu, IBAN ödeme onayı, USCIS takibi ve avukat dosya modülleri sunucu gerektirir; bu yayında pasif.

Skorlar hazırlık göstergesidir, vize onayı olasılığı değildir. Hukuki veya göçmenlik danışmanlığı değildir.

Yerelde: `index.html` dosyasını tarayıcıda aç.
